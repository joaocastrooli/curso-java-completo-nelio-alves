# ☕ Curso Java — Exercícios e Estudos

Repositório destinado aos exercícios, exemplos e práticas desenvolvidos durante o curso de **Java do Nélio Alves**.

O objetivo deste repositório é registrar minha evolução no aprendizado de Java, praticando os conceitos apresentados ao longo do curso e construindo uma base sólida em **Programação Orientada a Objetos**.

## 📚 Conteúdos estudados

* Sintaxe e fundamentos do Java
* Variáveis e tipos de dados
* Estruturas condicionais
* Estruturas de repetição
* Métodos
* Classes e objetos
* Construtores
* Encapsulamento
* Modificadores de acesso
* `this`, `static` e `final`
* Sobrecarga
* Herança
* Polimorfismo
* Upcasting e Downcasting
* Classes abstratas
* Interfaces
* Enums
* Exceções
* Collections
* Generics
* Lambda e Stream
* Manipulação de arquivos
* Outros conceitos abordados durante o curso

## 🎯 Objetivo

Utilizar este repositório como um registro da minha evolução durante o aprendizado de Java, colocando em prática os conceitos estudados e desenvolvendo cada vez mais minha lógica de programação.

> Aprendendo na prática, um exercício de cada vez. 🚀
